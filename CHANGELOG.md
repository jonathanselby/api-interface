# Changelog

## 0.1.0 — Initial release candidate

- Small standard-library Go HTTP/JSON interface for direct and gateway-backed applications.
- Explicit immutable routes and generated/served OpenAPI 3.0.3.
- Request/correlation/trace context and trusted middleware identity hand-off.
- Strict bounded JSON, typed error envelopes, idempotency-key and pagination helpers.
- Optional trusted-proxy CIDRs, health and readiness endpoints.
- Example application, adversarial tests, and native/ARM64 CI gates.
